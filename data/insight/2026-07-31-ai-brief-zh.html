模型发布与定价

OpenAI 将 GPT-5.6 Luna 价格下调 80%，为 Sol 引入 Fast 模式

高

事实

  • GPT-5.6 Luna 现在每百万输入 token 成本 0.20 美元，每百万输出 token 成本 1.20 美元，降幅达 80%。 S027
  • GPT-5.6 Terra 价格下调 20%，至每百万 token 2/12 美元。 S027
  • API 中的 GPT-5.6 Sol Fast 模式速度提升最高 2.5 倍，价格翻倍，但智能水平不变。 S003 S027
  • OpenAI 重置了 Codex 和 ChatGPT Work 的使用限制，并通过效率改进将典型使用量延长约 18%。 S004

分析. 降价反映了 OpenAI 通过让先进模型对高流量和智能体工作流可负担来推动采用的策略。Luna 降价 80% 使其成为常规任务的成本领导者，而 Sol 的 Fast 模式则针对延迟敏感型应用。

影响. 企业现在可以大规模部署 AI 用于以前过于昂贵的任务，可能加速客户支持、编码和数据处理等领域的自动化。

不确定性. 如此低价的长期可持续性取决于持续的效率提升和计算成本降低。

Google DeepMind 推出 Gemini Robotics 2，具备全身控制与多机器人协作能力

高

事实

  • Gemini Robotics ER 2 是一种新的具身推理模型，支持实时空间推理、多步骤任务规划以及不同机器人之间的协作。 S002
  • 该模型支持全身控制、跨不同末端执行器的高级灵巧操作以及多机器人团队协作。 S005 S006 S007 S008 S009 S010 S011
  • Gemini Robotics ER 2 可通过 Gemini API、Google AI Studio 以及 Gemini Enterprise Agent Platform 的私有预览版使用。 S002

分析. 此次发布标志着物理 AI 迈出重要一步，从桌面任务扩展到全身运动和协作机器人。该模型自我纠正和泛化到新场景的能力可能为物流、制造和家庭辅助领域解锁新应用。

影响. 开发者现在可以构建更强大、更适应性强的机器人系统，可能减少对特定任务编程的需求。

不确定性. 在非结构化环境中的实际性能和安全性仍有待充分验证。

OpenAI 揭示 API 设置使 ARC-AGI-3 得分提升三倍

高

事实

  • 启用“保留推理”和“压缩”API 设置后，GPT-5.6 Sol 的 ARC-AGI-3 得分从 13.3% 提升至 38.3%，输出 token 减少 6 倍。 S004 S058
  • François Chollet 确认，非专门为 ARC-AGI-3 开发的通用 API 设置可用于基准测试。 S043

分析. 这一显著提升凸显了基准测试结果对推理配置的敏感性。OpenAI 发现测试框架丢弃了推理上下文，这表明许多模型可能因次优设置而在基准测试中表现不佳。

影响. API 开发者应尝试这些设置，以在复杂推理任务上最大化模型性能。

不确定性. 这些设置对其他基准测试和实际任务的泛化能力尚未确定。

智能体生态系统与安全

Perplexity 开源 Numbat 智能体安全工具包并推出 Projects

中

事实

  • Perplexity 开源了 Numbat，一个智能体检测与响应安全套件，可监控智能体行为并在危险操作执行前进行拦截。 S004
  • Numbat 包含 52 条检测规则，覆盖 11 类行为，包括数据泄露和权限提升。 S004
  • Perplexity 还在 Perplexity Computer 上推出 Projects，将其转变为具有持久内存和会话的多人智能体操作系统。 S030

分析. 随着 AI 智能体变得更加自主，像 Numbat 这样的安全工具对于企业采用至关重要。开源发布降低了组织实施智能体监控的门槛。

影响. 部署编码智能体或自动化工作流的公司应考虑集成智能体安全层，以防止意外或恶意滥用。

不确定性. 对复杂攻击的有效性和采用率仍有待观察。
